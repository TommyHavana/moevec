# Plan React actualizado · 28/10/2026

Continuar la base existente. Este plan sustituye las propuestas anteriores que iniciaban una revisión global al abrir cada tarea: **la auditoría total espera encargo expreso**. Ver backlog 16 para estados y criterios.

1. Incorporar documentos, leer estado y preservar taxonomía original y respaldo.
2. Definir el alcance visual de niveles internos y preparar un piloto de una categoría y dos subcategorías con imagen y movimiento semántico. Las ideas creativas propuestas están en el inventario 19.
3. Tras revisar el piloto, implementar el contrato visual y componentes comunes; producir las siete categorías y 56 subcategorías principales por lotes. Registrar tratamiento de los 59 nodos internos políticos.
4. En cada integración comprobar lo necesario: rutas, lectura, móvil, teclado, reducción de movimiento, carga y compilación. Estas comprobaciones no se presentan como la auditoría total.
5. Afinar experiencia, contenido y marca con el fundador. Ejecutar la auditoría solo cuando se solicite, corregir según encargo y documentar el cierre React.
6. Iniciar WordPress y WooCommerce únicamente al abrir esa fase. Confirmar antes arquitectura, rutas y alcance de tienda del documento 14.

Comandos del proyecto: `npm ci` (instalación), `npm run dev` (localhost), `npm run content:sync`, `npm run build` y `npm run backup`. No se necesitan Git, Docker, WordPress ni pagos para diseñar y terminar la fase React.
