# Inventario visual de MEE

Fecha: 28/10/2026. **Inventario y propuestas creativas; no implica producción ni aprobación.**

Siete categorías y 56 secciones principales: 63 fichas con propuesta. Además, 48 temas y once subtemas políticos: 59 fichas internas pendientes de tratamiento. Total: 122 nodos.

Todas las categorías ya tienen una primera imagen; no se ha verificado aquí su movimiento semántico. Las subcategorías no tienen imagen propia implementada en la plantilla examinada. El JSON de planificación está en `../inventario/visuales.json` después de instalar este paquete.
