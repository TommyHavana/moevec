Integración para terceros

Publica las tasas en tu sitio

Elige la vía que mejor se adapte a tu integración: Widget, API REST o MCP para apps inteligentes.

Recursos oficiales BCC
  • Integra en 2 minutos

    Widget oficial

    Inserta un iframe y muestra las tasas en tu sitio sin programación adicional.

    Ver detalles del iframe y ejemplo.

    Para publicar las tasas en tu página, inserta nuestro widget mediante un iframe: 

    <iframe
  src="https://www.bc.gob.cu/widget/tasas-de-cambio"
  style="width:100%;height:520px;border:0;"
  loading="lazy"
  referrerpolicy="no-referrer"
></iframe>

    Ajusta el alto/ancho con el atributo style según tu diseño.

  • Integración profesional

    API oficial

    Endpoints públicos para tasas activas, por fecha y series históricas.

    Ver endpoints, ejemplos y documentación.
    Tasas activas:
    GET https://api.bc.gob.cu/v1/tasas-de-cambio/activas
    Tasas por fecha:
    GET https://api.bc.gob.cu/v1/tasas-de-cambio/activas-por-fecha?fecha=YYYY-MM-DD
    Histórico:
    GET https://api.bc.gob.cu/v1/tasas-de-cambio/historico

    Parámetros: fecha (YYYY-MM-DD), fechaInicio, fechaFin, codigoMoneda.

    curl "https://api.bc.gob.cu/v1/tasas-de-cambio/historico?fechaInicio=2026-01-01&fechaFin=2026-01-15&codigoMoneda=USD"

    Recomendación: cachea la respuesta en tu servidor para reducir carga.

    Documentación
    OpenAPI / Swagger:

    Contrato técnico de la API: sirve para entender endpoints y probarlos desde el navegador.

    https://api.bc.gob.cu/docs
    SDMX-JSON:

    Formato estadístico estándar: facilita integrar datos en herramientas de análisis.

    GET https://api.bc.gob.cu/v1/tasas-de-cambio/sdmx
    Feed JSON:

    Canal de novedades: permite leer actualizaciones sin consultar todo el API.

    GET https://api.bc.gob.cu/v1/tasas-de-cambio/feed.json
    Webhooks:

    Notificaciones push: tu sistema recibe eventos cuando cambian las tasas.

    POST https://api.bc.gob.cu/v1/tasas-de-cambio/webhooks/subscribe
    Integridad:

    Verificación de datos: compara el hash para confirmar que no fue alterado.

    GET https://api.bc.gob.cu/v1/tasas-de-cambio/integrity
  • IA-ready / apps inteligentes

    MCP

    Conecta asistentes y agentes con datos oficiales vía Model Context Protocol.

    Ver guía rápida, headers y ejemplos.

    Documentación MCP

    Uso básico del endpoint MCP

    MCP permite que asistentes y agentes consuman herramientas de tasas sin integrar la API manualmente. El flujo básico es: inicializar sesión, y luego llamar tools.

    Endpoint MCP:
    POST https://api.bc.gob.cu/v1/mcp
    Headers:

    Enviar Content-Type: application/json y Accept: application/json, text/event-stream.

    Initialize (primer paso):
    {"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25"}}
    Tools (ejemplo):
    {"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"get_active_rates","arguments":{"codigoMoneda":"USD"}}}

    En la respuesta de initialize recibirás el header MCP-Session-Id para usarlo en llamadas siguientes.
