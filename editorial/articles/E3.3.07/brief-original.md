#### E3.3.07 · Diseñar para conexiones lentas: lo que aprendió MEE
`disenar-para-conexiones-lentas` · **Desarrollo** · Etiquetas: accesibilidad, desarrollo
- **Pregunta del lector:** ¿Cómo hacer una web que cargue con mala conexión?
- **Tesis:** Imágenes ligeras, texto primero y carga progresiva son decisiones de inclusión.
- **Est.:**
  - H2 · Peso medio de las webs (HTTP Archive)
  - H2 · Técnicas: imágenes optimizadas, carga diferida, modo texto
  - H2 · Medir en condiciones reales
  - H2 · El mejor argumento en contra: el diseño visual atrae
  - H2 · La lectura de MEE
- **Fuentes:** HTTP Archive, *Web Almanac* (https://almanac.httparchive.org); web.dev (Google).
- **Imágenes:** *Destacada:* una página web que llega como un velero ligero. *Interior 1:* una mochila pesada frente a una ligera. *Interior 2:* un texto que aparece antes que las imágenes.
- **Meta:** Diseñar webs para conexiones lentas: peso medio, técnicas de optimización y por qué son una decisión de inclusión.
