Metodología y leyenda completa
Metodología
Consideramos bloqueo de internet a una medida técnica implementada para impedir el acceso a un servicio, sitio o página web mediante interferencia en el tráfico de internet. Siempre que cumpla los criterios de VE sin Filtro:
Es observable y medible técnicamente
Es consistente en el tiempo y en distintos puntos de acceso a la red
Se pueda descartar otras explicaciones, como una falla técnica
Para documentar los bloqueos se utiliza una mezcla de mediciones de red realizadas mediante
OONI Probe
, junto con otras pruebas para fortalecer la validación de hallazgos.

Leyenda
DNS
El servidor DNS del proveedor de internet devuelve una respuesta falsa o vacía para el dominio.
HTTP
Bloqueo HTTP o HTTPS usando inspección de paquetes, por ejemplo por el contenido de una página HTTP o el identificador del servidor al iniciar conexiones HTTPS (SNI).
IP
No es posible establecer conexión con la dirección IP del servidor.
OK
Sin bloqueo detectado, el sitio es accesible desde este proveedor.
desbloq.
Sitio desbloqueado después de septiembre de 2026.
*desbloq.
Desbloqueado desde el 25 de septiembre de 2026: el dominio estaba bloqueado y volvió a responder en la medición de ese día.

†
