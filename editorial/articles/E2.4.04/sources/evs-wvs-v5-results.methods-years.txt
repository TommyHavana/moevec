Documentation provided along with the data 
The Variable Report–Tables provides frequency counts for almost all variables. Results are 
weighted by gwght and usually broken down by country/territory. For variables with long lists of 
real values (e.g., age), results are only presented for the corresponding categorized variable if 
available.  
 
Countries surveyed in both EVS and WVS with separate samples are presented by country/study in 
the tables. Beware of the different fieldwork periods for each country's survey when comparing the 
results! In some cases, the interval between the surveys is large (e.g., the Netherlands EVS: 2017 vs 
WVS: 2022), partly because this includes the outbreak of the COVID-19 pandemic. The fieldwork 
period by country (and survey program source) is provided in the Joint EVS/WVS Participating 
Countries and Territories (Excel file). 
The purpose of the Variable Report–Documentation is to explain the structure of the Joint 
EVS/WVS 2017-2022 Dataset and its correspondence with the EVS 2017 (doi:10.4232/1.13897) and 
WVS7 (doi:10.14281/18241.24) source data files.   
It describes the Common Dictionary agreed upon by EVS and WVS, the international and survey-
specific standards that form the basis for harmonizing the data. It also provides information on the 
necessary recoding to map the common EVS and WVS core questions.  
The Excel file Joint EVS/WVS Variable Correspondence provides an overview of variables included 
in the Joint EVS/WVS and the source datasets EVS 2017 and WVS7. 
The Excel file Joint EVS/WVS Participating Countries and Territories provides an overview of 
countries and territories included in the current version of the Joint EVS/WVS and summarized 
information on fieldwork. 
The documentation provided on the Joint EVS/WVS is available via the EVS or GESIS websites and 
the WVS website. 
Comprehensive documentation of the EVS 2017 and WVS7 source datasets (guidelines, 
master/field questionnaires, methods and variable reports) not only helps users explore the data 
but also shows how the recommendations and standards have been implemented to allow for an 
assessment of data quality, is available on the EVS 2017 and WVS7 websites.
